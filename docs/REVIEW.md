# WESI 第一轮基础功能审阅

审阅范围：全部 Python 源码、空模块、依赖声明、工具脚本、README、仓库开发说明，以及 JSON 数据结构与牌面资源。个人记录和诗词 token 未写入本报告。

本轮目标是让基础功能能够稳定运行并正确保存，工资只在用户设定的上下班时间内累计。DX27 是仍在开发中的股票预警和交易系统，按用户要求暂缓集成。

| 优先级 | 原问题 | 本轮结果 |
| --- | --- | --- |
| P0 | `main.py` 使用未导入的 `Optional`，无法启动；无版本限制的依赖会安装不兼容的 ttkbootstrap | 存储类移至 `storage.py`，固定已验证的依赖版本，主窗口成功启动 |
| P0 | 存档解析失败直接覆盖默认数据；直接写入可能留下半个 JSON | 写入使用临时文件和原子替换，拒绝 NaN/Infinity；损坏或不兼容的原档先备份，权限及 I/O 错误不静默重置 |
| P1 | 工资流速按工作时长计算，金额按全天计算；月/年收入可能包含入职前工作日 | `income.py` 使用一致的班次算法，累计起点限制到入职时刻，覆盖跨月跨年、周末及入职当天 |
| P1 | 刚启动时把今日全部累计显示成“刚刚回收” | 首次显示的增量为零；修改设置后重置增量基准 |
| P1 | 工资输入允许 NaN/Infinity；日期和时段未充分校验 | 设置验证有限正数、有效日期、有效当日上下班时段，并实际测试界面保存 |
| P1 | 战斗点击后未保存最新统计；击杀成就检查先于击杀计数增加 | 命中与击杀及时保存，再检查成就；结束后点击不重复计数；缺失词库有本地回退 |
| P1 | 诗词 HTTP 请求在 Tk 主线程执行，网络失败无法使用内容库 | 请求使用后台线程和队列，主线程更新界面；失败回退本地内容或个人记录，避免重复提交请求 |
| P1 | 塔罗只读取未提交的生成文件，实际牌库为空 | 使用已有的源牌库和翻译表，补齐 78 张牌与已有图片的映射，无需额外下载 |
| P1 | 塔罗回车绕过按钮冷却，关闭重开也可绕过 | 逻辑入口检查冷却，重开参考最后抽牌时间；销毁窗口取消冷却回调 |
| P1 | 宠物任务依附窗口，关闭即丢失，可通过多窗口重复启动 | 任务由主应用管理，保存完成时刻，窗口关闭后继续，程序启动恢复待完成任务，并避免重复结算 |
| P1 | 子控件销毁会清除整个窗口注册，导致重复窗口 | 仅顶层窗口销毁时清理注册；统一收藏、记录、图鉴和历史入口 |
| P2 | 无效主题颜色可能写入存档并导致刷新失败 | 先校验主题和颜色再保存；旧档无效主题/颜色回退默认值 |
| P2 | 图片导入未验证内容，秒级命名可能覆盖同名图片 | 校验图片内容，使用唯一文件名，导入失败显示提示 |
| P2 | 生成脚本依赖当前目录和缺失的输入文件 | 输入默认路径相对仓库，支持指定输入/输出，缺失增强数据时使用现有源牌库 |

本轮保留现有用户存档与内容，不进行全量重写。新增字段默认补齐，未知扩展字段保留，并记录 `schema_version=1`；这仍是单实例 JSON 存储，不支持两个程序同时写同一个存档。

## 明确保留的限制

- 工资是基于平均工作日的估算，不保证每个自然月累计恰好等于月薪。当前为周一至周五当日班次，无节假日、午休、跨夜排班或历史薪资表。修改设置会重新估算历史金额。
- JSON 已有基础类型和关键工资字段校验，尚未建立所有历史记录条目的完整 schema 与迁移机制。
- 头像和宠物的旧绝对路径可能依赖原机器；尚未迁移为可打包的相对资源引用。
- `main.py` 仍包含多个窗口；`pet_window.py`、`theme_dialog.py` 为空。后续逐步拆分时应迁移实现与测试，避免同时维护两套逻辑。
- D2 词库可以加载，但当前掉落逻辑未使用这些名称；图像生成按钮仍为占位功能，不能视为已实现。
- 自定义主题的 accent/card_bg 尚未完整应用于所有组件；窗口适配、列表滚动、统一间距和配色属于下一轮 UI 工作。
- 收藏与历史窗口的实时联动刷新、完整数据导出/导入、撤销和多版本备份仍可继续完善。
- 本轮不建立 DX27 API、不涉及交易行为或凭据。将来需要确认双方的数据协议和授权边界，再设计互操作。

## 验证与后续顺序

回归测试包含工资边界和流速一致性、存档损坏备份及写入失败、完整牌库与资源，以及真实 Tk 窗口中的设置保存、战斗统计、宠物任务、塔罗抽牌和冷却、网络等待时界面响应与离线收藏。
GUI 测试使用独立临时目录；没有图形显示时会明确跳过，不把跳过当作通过。

建议下一轮先完善基础体验：内容库入口与刷新、可导出存档、宠物图鉴和成就反馈；随后统一主界面导航、响应式布局与主题。基础功能和数据协议稳定后，再评估 DX27 的只读提醒展示或事件交互。具体集成功能尚未约定。
